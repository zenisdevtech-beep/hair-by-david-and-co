## 🌟 Overview

A modern, high-end, multi-page web application engineered specifically for **Hair By David & Co.**, an elite Toronto hairdressing and colour studio celebrating 23 years of artistry in the historic Fashion District.

Built with **React 18**, **Vite**, **Tailwind CSS**, **React Router v6**, **Lucide Icons**, and **Canvas Confetti**, featuring a responsive editorial design with champagne gold & obsidian noir aesthetics, micro-interactions, and mobile navigation.

## 🚀 Live Pages & Features

### 1. Home Page (`/`)
- **Editorial Fashion Hero**: Gold-gilded badge showcase celebrating 23 years, 4.8-star Google rating with 511 verified reviews, live studio status pill (`Closed · Opens 10:30 am`), dual CTAs for instant online booking and the interactive hair consultation quiz.
- **The Salon Menu at a Glance (Redesigned)**: Interactive category tabs right on the homepage showing top services, prices, durations, and instant reservation buttons.
- **Interactive Before & After Split Slider**: Draggable slider comparing real transformations (brass to sun-kissed balayage, heavy lengths to architectural French bob, frizzy curls to mirror-sleek Cezanne keratin).
- **The Four Pillars of Craft**: Detailed cards for short & medium haircut architecture, dimensional French balayage, formaldehyde-free Cezanne keratin, and bridal/TIFF event styling.
- **Interactive Hair Investment Estimator**: Upfront investment & duration preview based on hair length, service, and luxury add-on rituals.

- **Live Instagram Showcase**: Dynamic feed preview from `@hairbydavidandco` (1.8K+ followers).
- **FAQ Accordion & Final Booking Banner**: Instant answers and reservation links.

## 🛠️ Development & Build Commands

```bash
# Navigate to the project directory
cd hair-by-david-and-co

# Start the local development server
npm run dev

# Build production distribution
npm run build

# Preview production build locally
npm run preview
```
